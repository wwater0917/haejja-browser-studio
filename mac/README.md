# 맥 연결 제작기

웹은 https://haejja-reel-studio.onrender.com 이며, 영상·AI 작업은 사용자의 맥에서 실행한다. 연결 설정은 `~/.config/haejja/relay.json`(권한 0600)에만 저장한다. 키를 저장소에 넣지 않는다. `studio`는 기존 릴스 제작실 경로, `url`은 보조 서버 HTTPS 주소, `key`는 해당 서버의 RELAY_WORKER_KEY와 일치해야 한다.

`python3 mac/start.py`가 맥의 제작 서버(127.0.0.1:8766), 필요하면 Ollama(127.0.0.1:11435), 바깥으로 요청하는 연결 worker를 실행한다. 로컬 디스크나 셸을 원격으로 실행하는 API는 없다. worker는 정해진 제작 API와 프로젝트 영상 경로만 중계한다. 웹 연결 코드는 매일 바뀌고, 연결된 브라우저는 전용 토큰을 저장한다. 웹 API/영상은 인증 없이 열리지 않는다. 영상 다운로드 티켓은 파일별로 30분 후 만료된다.

원본과 제작 데이터는 기존 맥 채널 폴더에 보존한다. 웹 미리보기·저장을 위해 원본 및 결과 영상이 Render 서버를 경유하고 최대 1시간 임시 보관된다. 자막·편집 API 응답은 최대 20분 보관된다. 렌더 서버는 재시작할 수 있으므로 원본 저장소로 사용하지 않는다. 전송 보호 한도는 프로세스 메모리 기반으로 31일 900MB이며 재시작 시 초기화된다. 공급자 청구 한도를 대신하지 않는다.

중단: 맥의 연결 프로세스 또는 설치된 사용자 LaunchAgent를 종료한다. 웹에서는 오프라인 상태가 표시된다. 이미 시작한 제작은 맥 서버가 계속 실행 중이면 끝까지 진행한다. 공개 게시/자동 SNS 업로드는 없다.
