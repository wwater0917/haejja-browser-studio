내 작업

이 브라우저에 저장됩니다. 다른 기기로 옮길 때는 작업 백업을 사용하세요.

무료 버전의 기능과 보관 방식

영상 자르기·순서 변경, 제목과 자막, 원본 소리·음성·배경음악, MP4 출력을 기기 안에서 처리합니다.

자동 자막과 한국어 음성은 처음 실행할 때 무료 모델을 다운로드합니다. Wi-Fi에서 사용하세요. 기기에 따라 오래 걸릴 수 있습니다.

기존 맥 제작실의 유튜브 수집, 댓글 분석, 시각 근거 기반 AI 연출, 얼굴·자막 영역 인식은 이 버전에 포함되지 않았습니다. 기존 제작실은 그대로 보존되어 있습니다.

브라우저 데이터를 지우면 저장된 작업도 사라집니다. 중요한 작업은 ZIP으로 백업하세요. 웹 화면은 공개되지만 작업 파일은 공개되지 않습니다.

02 / EDIT

제목과 화면

제목·자막 위치와 영상 영역

1080 × 1920 기준 좌표입니다. 출력 해상도에 맞춰 자동 조정됩니다.

AI 제목·내레이션 초안

기기 내 AI를 사용합니다. 첫 실행 약 500MB 다운로드가 필요하고, 휴대폰에서는 느릴 수 있어요. 화면을 직접 보는 모델이 아니므로 장면 설명과 원문을 대조하세요.

사용할 구간

원본 재생 위치에서 구간을 나누거나 시작·끝 시간을 초 단위로 수정하세요. 순서대로 이어 붙입니다.

자막

자동 인식 결과는 원문입니다. 한국어 번역은 별도 버튼으로 실행하며, 첫 사용 시 큰 모델 다운로드가 필요하므로 Wi-Fi를 권장합니다. 자막 시간은 편집 완료 영상 기준입니다. 구간을 바꾼 뒤에는 시간을 확인하세요.

PREVIEW
