# 해짜 릴스 제작실 · 맥 연결 자동 제작

현재 기본 웹 화면은 **링크 → 자동 제작 → 결과 확인 → 필요한 부분만 수정** 흐름이다. 사용자가 2026-09-27에 무료 우선이며 제작할 때 맥을 켜도 된다고 선택하여, 기존 로컬 제작 엔진을 인증된 웹 연결로 제공한다.

- 웹: https://haejja-reel-studio.onrender.com
- 맥: 기존 릴스 제작실의 다운로드·Whisper·OCR·로컬 AI·TTS·FFmpeg를 실행한다.
- 맥 연결: `mac/start.py`, `mac/worker.py`; `127.0.0.1:8766` 제작 API만 중계한다. 외부에서 맥의 포트로 직접 접속하지 않는다.
- 중계 서버: `server/relay.py`를 `server/app.py`에 연결한다. `RELAY_WORKER_KEY` 환경변수가 필요하며 값은 코드에 저장하지 않는다.
- 첫 연결: 맥의 `웹 연결 시작.command`에서 코드 확인 → 웹에서 한 번 입력. 브라우저가 연결 토큰을 기억한다.
- 이후 사용: 링크를 넣고 자동 완성 버튼을 누른다. 제작은 맥에서 계속 진행하므로 웹 탭을 닫아도 맥은 켜 두어야 한다.
- 수정: 제목·번역·글꼴·배치·컷·음향·내레이션을 수정하고 다시 만들 수 있다. 저장된 사람 수정은 자동 재생성으로 덮어쓰지 않는다.
- 기존 브라우저 파일 편집기는 `/manual.html`에 보존한다. 해당 IndexedDB 작업도 유지된다.

보안·프로세스·임시 보관 범위는 [mac/README.md](mac/README.md)를 따른다. 원본과 결과는 맥 채널 폴더가 원본 저장소이며, 웹 미리보기를 위해 Render에 임시 전송한다. 공개 사이트 주소만 알아서는 개인 작업이나 영상을 읽을 수 없다. 제작 중 오류는 해당 단계에서 실패로 표시한다. 단위 검사나 모델 응답 성공을 편집 품질 검수 통과로 간주하지 않는다.

빌드: `npm ci && npm run build`. 정적 게시 경로 `dist`. 서버: `pip install -r server/requirements.txt && python server/app.py`. 검증: `npm test`, `python3 -m unittest discover -s tests-python`. 맥 제작 엔진 검사는 해당 저장소의 unittest를 사용한다.

# 해짜 릴스 제작실 — 무료 웹 에디션

주소: https://haejja-reel-studio.onrender.com

영상 편집·보관·출력은 브라우저에서 처리한다. 한국어 온라인 음성은 무료 보조 서버를 사용한다. 기존 맥 제작실을 덮어쓰지 않고 별도 에디션으로 구성했다. 이 저장소에는 사용자 영상, 기존 채널, 계정 비밀, AI 모델 원본이 없다. 예제는 합성 테스트 패턴이다.

## 실행과 배포

Node 22 이상. `npm ci && npm run build`, `npm run preview`. 정적 사이트 게시 경로 `dist`.

무료 보조 서버: Python 3.12, `pip install -r server/requirements.txt`, `python server/app.py`. `PORT`와 `WEB_ORIGIN`을 환경변수로 설정한다. Render Free 플랜이며 영상 보관용 디스크나 유료 API가 없다. 서버가 15분간 쉬면 다음 요청에서 다시 시작하므로 첫 음성 요청은 약 1분 느려질 수 있다.

무료 호스팅의 월간 트래픽·빌드 한도는 별도다. 무제한 무료 보증이 아니다. 자동 유료 업그레이드를 구현하지 않았으며 비용 발생 서비스는 만들지 않는다. 보조 서버의 요청/전송 제한은 프로세스 메모리 기반 보호 장치이며 제공사 청구 한도를 대체하지 않는다.

## 기능

- 기기의 영상 선택, 구간 분할·제외·재정렬, 시작·끝 시간 편집
- 제목·자막·영상 영역 위치와 크기, 원본 전체 유지 또는 영역 채우기
- Whisper 원문 자막, SRT 불러오기·내보내기·직접 수정
- 한국어 번역 초안은 M2M100 전용 기기 내 모델로 처리한다. 원문을 함께 표시하고 복원할 수 있다. 짧은 영어 문장의 한국어 번역을 실제 브라우저에서 확인했다
- 인준·선희·현수 온라인 음성, Supertonic 기기 내 음성, 별도 녹음 파일
- 내레이션 시작·속도·높이(온라인)·음량, 내레이션 중 원본 소리 줄이기
- 배경음악, 팝·톡·스윽 효과음의 위치·종류·음량 및 대사를 피하는 자동 배치
- 720×1280 / 1080×1920 H.264/AAC MP4 출력
- 기기 내 작업 저장, 영상이 포함된 ZIP 백업·복원

## 남은 차이 — 완전한 전환 완료가 아님

기존 맥 제작실과 100% 기능 동등성이 아니다. 유튜브 링크 자동 수집은 실제 무료 서버 테스트에서 YouTube의 봇/로그인 제한으로 차단됐다. 쿠키나 우회 프록시를 사용하지 않는다. UI의 링크 입력은 출처 기록용이며 영상은 파일로 선택한다.

댓글 분석, 시각 근거 기반 AI 디렉터, 얼굴/OCR 분석, 원본 앱의 전체 검사·추적 원장, 사용자 글꼴 목록·개별 글꼴 선택, 여러 내레이션 구간의 기존 계획서 가져오기는 아직 이 에디션에 이식하지 않았다. 가벼운 범용 AI 모델의 번역·연출 품질이 검증을 통과하지 못해 AI 제목/원고 자동 생성 UI는 숨겼다. 기존 맥 앱의 서버와 데이터/백업은 유지한다.

자막·효과음 시간은 출력 영상 기준이다. 구간을 변경한 뒤 시간을 확인해야 한다. 기존 프로젝트가 이 웹 보관함에 자동 이전되지는 않는다. 이 ZIP 형식은 현재 웹 에디션 전용이다.

## 보관과 처리 범위

작업은 현재 브라우저의 IndexedDB에 보관된다. 기기 간 자동 동기화가 없으며 ZIP 백업으로 옮긴다. 브라우저 데이터를 지우면 작업이 사라질 수 있다. 파일 250MB 이하, 출력 180초 이하로 제한한다. 실제 휴대폰에서는 메모리에 따라 더 작은 파일이 필요하다.

Whisper·Supertonic·번역 모델은 기능 실행 시 Hugging Face에서 다운로드한다. 큰 다운로드이므로 Wi-Fi를 권장한다. 원본 영상과 자막은 외부 서버로 업로드하지 않는다. 온라인 인준·선희·현수를 선택하면 원고만 보조 서버를 거쳐 Microsoft 음성 서비스로 전달되며 음성 결과는 임시 보관 후 삭제된다. 보조 서버에 사용자 작업 목록이나 영구 미디어 보관함은 없다.

## 검증

`npm test`: 구간-자막 매핑, 잘못된 구간 거절, SRT, ASS 텍스트 이스케이프, 효과음 겹침 회피·공간 부족 거절·PCM 생성 검사.

브라우저에서 합성 예제의 MP4 생성 및 실제 다운로드를 검증했고 ffprobe로 H.264/AAC, 720×1280, 6초를 확인했다. 프레임 추출로 한글 제목·자막과 재정렬한 원본 시간이 출력 영상에 들어간 것을 확인했다. 영문 음성 파일의 자동 자막, Supertonic 한국어 음성, ZIP 백업·복원, 새로고침 후 저장 복원, 390×844 화면 가로 넘침을 점검했다. 실제 휴대폰 기기의 처리 속도·메모리 한계 및 전체 기존 기능 동등성은 미검증이다.
