# 해짜 릴스 제작실 — 무료 브라우저 에디션

정적 웹사이트와 브라우저 처리로 구현한 별도 에디션. 기존 Python/맥 제작실을 덮어쓰지 않는다. 원본 미디어·계정 정보·기존 채널 데이터는 이 저장소에 포함되지 않는다.

## 실행

Node 22 이상. `npm ci`, `npm run build`, `npm run preview`. 배포 빌드 `npm ci && npm run build`, 게시 경로 `dist`.

## 현재 기능

로컬 영상 선택, 구간 분할·제외·재정렬, 제목, SRT 자막, Whisper 원문 자막, Supertonic 한국어 TTS, 외부 음성·BGM, 원본/음성/BGM 볼륨, 9:16 MP4 출력, IndexedDB 작업 저장, ZIP 백업·복원. 모델은 사용자가 기능 버튼을 눌렀을 때 Hugging Face에서 기기로 내려받으며 사용자 원고와 영상은 서버에 업로드하지 않는다.

## 범위 및 한계

기존 앱과 완전한 기능 동등성이 아니다. 유튜브 자동 다운로드, 댓글 수집, 자동 번역·AI 연출, Apple Vision 기반 인식은 미포함. 기존 Edge/Yuna 대신 Supertonic 음성. 원본 파일 250MB 이하, 한 번에 출력 180초 이하. 브라우저 메모리·영상 코덱 지원에 따라 더 작은 파일이 필요하다. 무료 호스팅은 제공사 트래픽/빌드 한도 내 사용이다. 유료 서버나 유료 API는 연결하지 않는다.

작업은 브라우저 IndexedDB에 보관되며 자동 기기간 동기화가 없다. ZIP 백업으로 이동한다. 공용 PC에서는 브라우저 저장 데이터를 주의한다. 공개 사이트에는 사용자 미디어가 없고, 서버 인증 대신 로컬 기기 저장 범위를 사용한다.

## 라이선스

public/THIRD-PARTY.txt 및 라이선스 파일 참조. ffmpeg.wasm core가 포함된 앱 배포물의 라이선스 의무를 유지한다. 모델 소스/버전을 worker에 명시한다.
